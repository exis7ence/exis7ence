## Проекты

### [TODO Scheduler — планировщик задач](https://github.com/exis7ence/final_project)

Дипломный backend-проект на Go: создание и редактирование задач, поиск, правила повторения, выполнение и удаление. Данные хранятся в SQLite; предусмотрены JWT-аутентификация и запуск в Docker.

В проекте работал с HTTP-обработчиками, SQL-запросами, валидацией входных данных и расчётом следующих дат. После ревью исправил HTTP-коды ошибок и отделил внутренние ошибки базы от публичных ответов API. Проект принят на итоговом ревью.

**Стек:** Go, net/http, SQLite, SQL, JSON, JWT, Docker.

### [Parcel Tracker — учёт посылок](https://github.com/exis7ence/parcel-tracker-ci)

Учебное консольное приложение для регистрации посылок, просмотра отправлений клиента, изменения адреса и переходов между статусами. Код разделён на сервисный слой и работу с SQLite. В репозитории есть тесты, Dockerfile и workflow GitHub Actions.

**Стек:** Go, database/sql, SQLite, Docker, GitHub Actions.
